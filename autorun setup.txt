Install:
sudo apt-get update && sudo apt-get install -y xterm
pip3 install smbprotocol --break-system-packages

Setup:
mkdir /home/pi/.config/autorun
nano /home/pi/.config/autorun/autorun.desktop

Paste:
[Desktop Entry]
Type=Application
Name=Autorun Script
Exec=xterm -hold -e '/usr/bin/python3 /home/pi/Desktop/autorun.py'

Desktop:
Copy over autorun.py and modify vars to pull the correct folder/script from SMB.
